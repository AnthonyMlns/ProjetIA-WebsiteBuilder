description: Liste des livrables attendus par type de projet, à valider en début de mission
---
## Landing page (1-3 pages)
- [ ] Cahier des charges 1 page
- [ ] Wireframe des sections
- [ ] Design tokens (couleurs, fonts, espacements)
- [ ] Code HTML/CSS/JS responsive
- [ ] Formulaire de contact / newsletter
- [ ] Déploiement (Vercel / Netlify)
- [ ] SEO de base (meta, OG, sitemap)

## SaaS / Web app
- [ ] Cahier des charges complet
- [ ] Architecture technique (stack, data model, API)
- [ ] User stories priorisées (MoSCoW)
- [ ] Wireframes + user flows
- [ ] Design tokens + composants
- [ ] Frontend (pages, composants, routage, state)
- [ ] Backend (API, BDD, auth, logique métier)
- [ ] Tests (unit, intégration, E2E)
- [ ] CI/CD + déploiement
- [ ] Monitoring (Sentry, uptime, logs)
- [ ] Documentation technique + utilisateur

## E-commerce
- [ ] Cahier des charges + catalogue fonctionnel
- [ ] Architecture (paiement, stock, expédition)
- [ ] Wireframes : catalogue, fiche produit, panier, checkout
- [ ] Frontend : catalogue, recherche, filtre, panier
- [ ] Backend : produits, commandes, paiement, stocks
- [ ] Intégration paiement (Stripe / PayPal)
- [ ] Emails transactionnels (confirmation, expédition)
- [ ] Tests de paiement (sandbox + production)
- [ ] Déploiement + monitoring

## Blog / CMS
- [ ] Cahier des charges
- [ ] Architecture headless / monolithique
- [ ] Design tokens + composants
- [ ] Interface d'administration
- [ ] Frontend public (pages, articles, catégories)
- [ ] Newsletters / RSS
- [ ] SEO avancé (sitemap, structured data, OG)
- [ ] Multilingue (si requis)
- [ ] Module RGPD (politique confidentialite, cookies, mentions legales)
- [ ] Deploiement + backup automatise

## Checklist transverse (tous les projets)
- [ ] Pas d'emojis dans le code UI (icones SVG ou texte uniquement)
- [ ] Verification de la disponibilite des agents avant de lancer le pipeline
