## Par rôle

| Rôle | À impliquer pour | Quand |
|------|------------------|-------|
| **Décideur** (CEO, founder) | Vision, budget, priorité, validation finale | Début + fin de chaque phase |
| **Métier** (marketing, compta) | Contenu, règles métier, parcours utilisateur | Phase analyse + recette |
| **Tech lead / CTO** | Architecture, sécurité, stack | Phase architecture |
| **Designer** | UI/UX, charte graphique, accessibilité | Phase design |
| **DevOps** | Hébergement, CI/CD, monitoring | Phase déploiement |
| **Utilisateurs finaux** | Tests, feedback | Phase dev + QA |

## Par type de projet

### Landing page
- Décideur, Marketing

### SaaS
- Décideur, Tech lead, Utilisateurs beta

### E-commerce
- Décideur, Marketing, Compta/logistique, Tech lead

### Blog / CMS
- Marketing, Rédacteurs, Tech lead

### App interne
- Équipe concernée, Tech lead, DSI

## Checklist d'implication
- [ ] Le décideur a validé le périmètre
- [ ] Les utilisateurs finaux ont été consultés
- [ ] Le tech lead a validé l'architecture
- [ ] Le métier a validé les règles de gestion
- [ ] Le budget et délai sont acceptés par tous
